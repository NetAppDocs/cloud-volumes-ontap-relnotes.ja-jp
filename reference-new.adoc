= Cloud Volumes ONTAP 9.19.1 の新機能
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs:

[role="lead"]
Cloud Volumes ONTAP 9.19.1の導入およびアップグレードが可能になりました。このリリースのベースバージョンと、導入およびアップグレードに利用可能な最新のパッチバージョンは、NetApp Consoleで確認できます。

Cloud Volumes ONTAP の機能、サポートされる構成、制限などの詳細については、 https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html["Cloud Volumes ONTAPのドキュメント"^]を参照してください。



[[9-19-1-ga]]
== 9.19.1 GA

Cloud Volumes ONTAP 9.19.1一般提供（GA）版が、Amazon Web Services（AWS）、Microsoft Azure（Azure）、およびGoogle Cloudで展開およびアップグレードできるようになりました。



[[upgrade-notes]]
== アップグレードに関する注意事項

このリリースへのアップグレードの詳細については、以下のメモをお読みください。



[[how-to-upgrade]]
=== アップグレード方法

Cloud Volumes ONTAPのアップグレードはコンソールから完了する必要があります。System Manager または CLI を使用してCloud Volumes ONTAP をアップグレードしないでください。システムの安定性に影響を与える可能性があります。

https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-updating-ontap-cloud.html["コンソールから通知があった場合にアップグレードする方法を学びます"^].



[[supported-upgrade-path]]
=== サポートされているアップグレードパス

AWS、Azure、およびGoogle Cloudで、Cloud Volumes ONTAP 9.18.1から9.19.1にアップグレードできます。コンソールは、対象となるCloud Volumes ONTAPシステムをこのリリースにアップグレードするようにプロンプトを表示します。



[[downtime]]
=== ダウンタイム

* 単一ノード システムをアップグレードすると、システムが最大 25 分間オフラインになり、その間 I/O が中断されます。
* HAペアのアップグレードは無停止で実行され、I/Oが中断されることはありません。この無停止アップグレードプロセスでは、クライアントへのI/O処理を継続するために、各ノードが同時にアップグレードされます。
